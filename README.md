#sheep relay紹介


「sheep relay」は、宛先に名前を入れると、その人の元まですれ違い通信方式で手紙を届けてくれるメッセージアプリ

既存のメッセージアプリのように直接相手に届くわけではなく、
 
手紙を持った人が誰かとすれ違うたびに、その手紙は複製され、さらに別の人へと広がっていく。
 
一通の手紙を送り続けるのではなく、ウイルスのように手紙を持った人が拡散され続け
 
最終的に、指定した名前の人へ届いた時点で手紙の拡散は終了する


#使い方


###ユーザー登録

はじめに、ユーザー登録画面で自分の名前を入れ、BLE通信の設定で認証が終わるとユーザー登録が完了する。

その後「はじめる」のボタンが出てくるので、それを押すとホーム画面に遷移する

###ホーム画面

ホーム画面にはポストの画像が表示されており、ホーム、受信、配達、手紙を作成する用のボタンがある。

ホームボタンはホームに戻るときに使うボタンで、新しい手紙を受信すると表示されているポストに手紙が入っている見た目に変わる

###受信ボタン

受信のボタンを押すと受信した手紙の一覧が表示され、

既読か未読かで手紙の見た目が開封済かそうでないか変わる

手紙をタップすると受け取った手紙の内容、どんなルートをたどってきたのかが見れる。

それぞれをさらにタップすると画面に拡大されて内容が表示される


###配達ボタン


配達のボタンを押すと現在自分が保持しているほかの人の手紙が確認できる。内容は見れないが、送り主の名前と宛先が見れる。

配達が完了したら画像の色が変わり、宛先の後ろに『済』と表示される。


###手紙作成用ボタン


最後に、右下に表示されているペンと紙のボタンを押すと手紙が作成される。宛先とメッセージ、自分の名前を入れ、その後投函するボタンを押す

ここで戻るボタンを押すと下書きに残すか残さないか選べる。投函ボタンを押した後、現在地を中心としたマップが表示され、

そのマップから投函するポストを選ぶことができる。ポストを選択しすると手紙は投函され、「投函しました！」という画面とOKボタンが出るので、

OKボタンを押すとホームに戻る。
